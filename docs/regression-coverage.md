# Regression coverage

Every issue found in Latchkey has a case in a regressions group of
`macos/scripts/state-check/cases.json` and an automated test that fails without its fix and
runs in CI (CLAUDE.md, "Every issue becomes a regression case"). This table says which test
covers each case. Status: covered (a test already existed), new (added 2026-11-24), partial
(Latchkey's own part is tested; the rest needs a real site, the locked screen or Toni's
devices), manual (nothing Latchkey decides can be tested without those).
